# NMM Holdings website

A responsive, static website for NMM Holdings by Melton. No build tools are required: open `index.html` locally or publish the folder to GitHub Pages or another static host.

## Features

- Black-and-gold founder-led home page with animated mark, scroll reveals, responsive navigation, and a night portrait.
- Horizontal Polar product gallery with filters, quantity controls, a persistent cart, subtotal, and WhatsApp order draft.
- Services section for websites, branding, business profiles, posters, business cards, and computing support.
- Selected work links for Amadwala Aqua & Ice and Zweli Group.
- Direct WhatsApp contact at 075 144 3192.

## Product image and pricing notes

The package includes 59 Polar product pack shots downloaded from Polar's public product image catalogue. The gallery includes 59 product cards across Polar lollies, Polar Pops, Maxi, Rave and Woza sticks, 500ml cups, and selected 2L tubs. The official catalogue link covers additional ranges not included in this curated gallery. Product photography and product names belong to Polar Ice Cream; the official catalogue link is included for the broader range. Availability can vary by region and stock.

Prices are editable in the `products` list in `app.js`. The starting values reflect prices previously supplied for selected NMM products: Milky Pie R15, Strawberry Sensation R10, chocolate treat R12, fruit treats R7, 2L tubs R90 and 500ml tubs R35. Unpriced products display “Ask for price.” Please confirm current prices and sizes before publishing; final price, availability, and collection/delivery details are always confirmed in WhatsApp.

## Publishing

Upload the contents of this folder to a public GitHub repository and enable GitHub Pages from the repository's Pages settings. Cloudflare Pages can also connect to the repository and deploy the static folder, but no repository or Cloudflare account connection was available in the connected workspace during this build.
